# Description

## 中文版

云端1998 是一台跑在浏览器里的 1998 年中文复古电脑个人主页：打开网站即开机，桌面图标、可拖拽窗口、MS-DOS 终端、画板、贪吃蛇全部可交互，我的电脑实时拉取 GitHub 公开数据。开机一秒后，一只星露谷原版贴图的像素鸡「云咕咕」从屏幕左缘走进来常驻桌面：溜达啄食、闲置入睡，可拎起抛落、快速甩动把它踢飞（撞墙反弹满天羽毛）、撒谷粒喂食、右键查属性（蛋数/陪伴天数/随事件变化的心情）、被放生后用终端 chicken 命令召回，星空屏保时它浮在银河上继续溜达；它下的蛋有 8 秒倒计时——手快点击收集计数，手慢了破壳出跟屁虫小鸡（上限 2 只，排队跟妈妈走）。含金量在零依赖拟物工程：手写 358 行窗口管理器实现拖拽、焦点与任务栏联动，16x16 像素画稿运行时编译成 SVG 图标做到图标零图片文件（全站图片仅两张 1920 宽风景壁纸与一张鸡贴图集），鸡叫由 WebAudio 现场合成零音频文件，画板重力是欧拉积分粒子系统并带睡眠计数、粒子上限与超时三重性能保护，GitHub 数据经 sessionStorage 五分钟缓存与 AbortController 防竞态，并尊重系统减少动态设置自动禁用动画。基于 Vite + TypeScript 零 UI 框架零运行时依赖，应用构建产物约 92KB，适合复古拟物个人主页与无框架 DOM 工程参考。

## English

Cloud 1998 is a personal homepage disguised as a 1998 Chinese Win98 PC: opening the site boots it up, and every desktop icon opens a draggable window — an MS-DOS terminal with real commands, a paint app, Snake, Notepad, and a My Computer panel pulling live GitHub stats with zero backend. One second after boot, Gugu — a desktop chicken rendered with Stardew Valley's original sprite sheet — struts in from the left edge and never leaves: she wanders, pecks, falls asleep when ignored, can be picked up and dropped, flung across the screen with a fast swipe (bouncing off the walls in a burst of feathers), fed with scattered grains, inspected through a Win98-style properties dialog (egg stats, days together, an event-driven mood line), released via her context menu and recalled with the terminal command `chicken`, and keeps strolling across the galaxy when the starfield screensaver kicks in. Her eggs run an 8-second countdown — click fast to collect them for the counter, or let one hatch into a chick that queues behind her (up to two). The engineering is handmade throughout: a 358-line framework-free window manager (drag, focus z-ordering, taskbar sync, Promise-based dialogs), a runtime pixel-icon compiler that turns 16x16 character sketches into crisp SVGs so icons ship zero image files (the only images are two scenic wallpapers and one chicken spritesheet), clucks synthesized live with WebAudio so the site ships zero audio files, a gravity easter egg powered by a hand-rolled Euler-integration particle system with sleep counting and a particle cap, GitHub data cached in sessionStorage with AbortController race protection, and prefers-reduced-motion support that fast-forwards boot and disables screensavers. Built with Vite + TypeScript, no UI framework, no runtime dependencies, about 92KB of app code. A compact reference for skeuomorphic personal sites and framework-free DOM engineering.
