# Description

## 中文版

云端1998是浏览器里的1998年中文复古电脑个人主页：打开即开机，15个程序皆可交互——我的电脑实时拉GitHub数据、五页仿真内联网、扫雷贪吃蛇计算器画板、藏蓝屏彩蛋的MS-DOS终端，还有会下蛋孵小鸡的像素鸡云咕咕。含金量在零依赖拟物工程：手写483行窗口管理器，拖拽、八向缩放、焦点任务栏联动；23枚16×16字符画稿运行时编译成SVG，图标零图片；音效WebAudio现场合成零音频文件；埋点与25枚成就引擎解耦，Steam式通知补发老战绩；GitHub数据sessionStorage五分钟缓存加AbortController防竞态；WebGL2星空屏保缺失时降级Canvas 2D。Vite+TypeScript零运行时依赖，产物约92KB，适合复古拟物主页与无框架DOM工程参考。

## English

Cloud 1998 is a personal homepage disguised as a 1998 Chinese PC. Opening the site boots the machine — a BIOS memory count, a splash chord, then a desktop where every icon opens a real window: My Computer pulling live GitHub stats with zero backend, a five-page fake intranet complete with dial-up failures, Minesweeper with first-click safety and chording, a calculator whose divide-by-zero is politely declined by the universe, and an MS-DOS terminal where sudo rm -rf / ends exactly as badly as it should. One second after boot, Gugu struts in from the screen's edge — a desktop chicken with a 14-state brain who wanders, naps, lays eggs on an 8-second countdown (miss one and it hatches into a chick that queues behind her, up to two), and bursts into feathers when flung against a wall. The engineering is handmade throughout: a 483-line framework-free window manager (drag, eight-way resize, z-order focus, taskbar sync, Promise-based dialogs), a runtime pixel-icon compiler that turns 23 hand-drawn 16x16 character sketches into crisp SVGs so icons ship zero image files (three images in the whole site: two wallpapers and one chicken spritesheet), every sound synthesized live with WebAudio so it ships zero audio files, an achievement engine of 25 unlocks — 12 hidden — fed by a decoupled stats bus with Steam-style toasts and silent retro-awarding for returning players, GitHub data cached five minutes in sessionStorage with AbortController race protection and textContent-only rendering, and a hand-written WebGL2/GLSL starfield screensaver that steps down to Canvas 2D when WebGL2 is missing. Built with Vite + TypeScript, zero runtime dependencies, about 92KB of app code. A compact reference for skeuomorphic personal sites and framework-free DOM engineering.
